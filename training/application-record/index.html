01

What it is

One attempt to enter one program for one term

An application belongs to a person record. It can't exist on its own.

A person can have many applications over the years, and each one is its own record with its own status and its own decision.

If the person record is a file folder with their name on it, each application is a separate form inside that folder, filled out for one program and one term.

1 program+1 term=1 application

Status

From started to decided

Application status tracks where this one application is in the process right now. There are four, in order.

The materials checklist

Every application has its own checklist

Each required item is marked received or missing. “Who still owes materials?” is one of the most common lists anyone asks for, and it's a list of applications, because the checklist belongs to the application. Tap the items to mark them received.

Recap

What to remember

One attempt

One application is one attempt to enter one program for one term. One person can have many.

Application fields

Facts about that one attempt: program, term, round, status, decision, materials.

Status

Awaiting Submission, Awaiting Payment, Awaiting Materials, Decided.

Decided is not a decision

The decision code tells you the outcome: AT, ATP, DF, DN.

Where decisions live

On the application, never on the person. Admission moves the person to Student.

Count carefully

Applications and people are different numbers. Say which one you mean.
